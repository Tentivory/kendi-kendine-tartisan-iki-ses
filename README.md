# Kendi Kendine Tartışan İki Ses

Bu repo, insanlığın en büyük sorusunu çözmek için tasarlanmamıştır. Aksine, hiçbir şeyi çözmez. Sadece iki sesin kendi kendine, tamamen anlamsız ve abartılı bir şekilde Türkçe tartışmasını simüle eder.

## Neden Var?

Çünkü birisi "durduk yere repo aç" dedi. Ve işte buradayız. Bu, GitHub tarihinin en anlamsız ama en çalışan tartışma simülatörüdür. Gerçekten çalışır. Şaka değil.

## Nasıl Çalıştırılır?

```bash
python tartisma.py
```

Çıktıyı izle, gül, sonra "neden yaptım bunu" diye sor.

## Özellikler

- Gerçekten çalışır.
- Hiçbir şey öğretmez.
- Anlamı yoktur.
- Ama Türkçedir.
